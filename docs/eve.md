# Eve

**My AI development layer.**

Eve brings AI assistance into the development workflows behind my products. The layer includes pull-request summaries and visibility into development sessions — context alongside the work rather than another disconnected chat window.

It sits alongside [Devbox](devbox.md), where development processes run, and [vitrinka’s public tooling](https://github.com/henderson-tech/vitrinka-kit), which connects visual feedback to agent-assisted work.

This is a public introduction, not a source release or an invitation to access an internal deployment. Eve’s application source remains private.
