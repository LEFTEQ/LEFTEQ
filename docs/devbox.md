# Devbox

**Build here. Run there.**

Devbox gives my projects remote development workspaces. My laptop owns the source edits; development servers, builds, and tests run in isolated remote environments.

The goal is straightforward: keep the laptop responsive, give each branch a repeatable place to run, and make the running app easy to reach for hand-testing.

Devbox is the execution environment alongside [Eve](eve.md), my AI development layer, and [vitrinka’s public tooling](https://github.com/henderson-tech/vitrinka-kit), the visual feedback side of the workflow.

This page is a public overview. Devbox’s source and operational infrastructure remain private; this is not an install guide or a hosted-service offer.
